# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

SysML v2 model library for antenna/RF systems engineering, consumed through
`sysml2kit`. Apache-2.0. The kit (github.com/jman4162/sysml2kit) stays
domain-general; RF vocabulary lives here.

**Source of truth is `src/sysml2kit_rf_library/_build.py`** (builder-API
construction, full fidelity). Everything under `src/sysml2kit_rf_library/models/`
is generated by `scripts/regenerate.py` — never edit those files by hand;
edit `_build.py` and regenerate. CI fails when they drift.

## Commands

```bash
uv sync --group dev                      # set up (depends on sysml2kit from PyPI)
uv run python scripts/regenerate.py      # rebuild models/*.sysml and interchange/*.json
uv run pytest
uv run ruff check . && uv run ruff format --check .
uv run mypy
scripts/slopcheck.sh                     # prose lint, advisory
```

During lockstep development against a local sysml2kit checkout:
`uv run --with-editable ../sysml2kit ...`.

Release: tag `vX.Y.Z`; `release.yml` publishes via Trusted Publishing
(environment `pypi`). Version from git tags (hatch-vcs).

## Constraints

- Model content is authored fresh: never copy text from the EPL-2.0 OMG
  normative libraries. Reference ISQ/SI symbols by import name only.
- The `metricKey` convention (owned attributes metricKey/threshold/op/severity
  on requirement usages) is the contract `sysml2kit.interop` reads — changing
  it breaks downstream extraction; coordinate with the kit first.
- The t3-001 example mirrors `aedl/tasks/t3-001-satcom-terminal-28ghz/task.yaml`;
  keep thresholds in sync with that file.
